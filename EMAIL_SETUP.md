# Email Notifications — Complete Setup

## What you have now

An **Email Notifier** that:
- ✅ Reads the digest generated by the pipeline
- ✅ Formats it as a nice-looking HTML email
- ✅ Sends it to your email via Gmail SMTP
- ✅ Runs automatically after the digest is generated

---

## Required Configuration

### STEP 1: Generate a Gmail App Password

Gmail does not allow direct access with your normal password (for security). You need an **App Password**.

**How to generate one:**

1. Go to: https://myaccount.google.com/apppasswords

2. If it asks for 2FA, enable it (it's secure)

3. Select:
   - App: **Mail**
   - Device: **Windows/Mac/Linux**

4. Click **Generate**

5. Gmail will generate a **16-character** password
   - Example: `abcd efgh ijkl mnop`
   - **Copy it and store it somewhere safe**

⚠️ **IMPORTANT:** This is different from your Gmail password!

---

### STEP 2: Add Secrets on GitHub

You need to add 2 secrets:

1. Go to: https://github.com/your-username/job-hunt-pipeline/settings/secrets/actions

2. Click **"New repository secret"** (first time)

3. Add:

```
Name: GMAIL_APP_PASSWORD
Value: (the 16-character password you generated above)
Example: abcdefghijklmnop
```

4. Click **"Add secret"**

5. Repeat to add a second one (optional):

```
Name: GMAIL_RECIPIENT
Value: your.email@gmail.com
```

### STEP 4: Integrate into the Pipeline

Edit the file `.github/workflows/job-hunt-scheduler.yml`:

Find the `Run Job Hunt Pipeline` section and add at the end:

```yaml
      - name: Send email notification

        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
          GMAIL_APP_PASSWORD: ${{ secrets.GMAIL_APP_PASSWORD }}

          python agents/email_notifier.py || true
```

**Complete example:**


## What happens now

**On every pipeline run (7 AM and 2 PM):**

1. ✅ Pipeline runs (ingest → parse → eval → digest)
2. ✅ Generates the digest (`digests/digest_latest.json`)
3. ✅ **Email Notifier reads the digest**
4. ✅ **Formats it as nice-looking HTML**
5. ✅ **Sends it to you via Gmail**

**What you receive in the email:**

- Subject: `📊 Job Hunt Digest — May 17`
- Body:
  - Total jobs found
  - Top 5 jobs with score
  - Links to each job
  - Call-to-action to open the dashboard

## Troubleshooting

### Problem: "GMAIL_APP_PASSWORD not configured"

**Solution:**
- Check that you added the secret on GitHub
- Wait 1-2 minutes after adding it (GitHub needs to sync)
- Test by running manually: GitHub → Actions → "Job Hunt Daily Pipeline" → "Run workflow"

### Problem: "Invalid credentials"

**Solution:**
- Check that the password has exactly 16 characters
- Make sure you copied it correctly (no extra spaces)
- Try generating a new App Password

### Problem: "Email didn't arrive / went to spam"

**Solution:**
- Check the spam folder
- Add the email address to your trusted contacts list
- If it keeps going to spam, that's normal with Google (mark it as a trusted contact)

### Problem: "SMTPAuthenticationError"

**Solution:**
- Make sure 2FA is enabled on the Google account
- Try generating a new App Password
- Use exactly the 16-character password

### Conditional Notification (only with new jobs)

If you want to receive email **only when there are new jobs** (not every day):

Edit `agents/email_notifier.py` and add:

```python
def notify_digest():
    ...
    digest = load_digest()
    
    # Only send if there are jobs with score >= 75 or >= 55
    apply_jobs = [j for j in digest.get("top_jobs", []) if j.get("score", 0) >= 55]
    
    if not apply_jobs:
        print("No interesting jobs today, email not sent")
        return True  # Success, but no email
    
    ...
```
